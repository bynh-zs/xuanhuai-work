## 3. 登录链路

```
报销网页 → 飞书授权页（redirect_uri 为后端回调）
        → 回调携带 code → 后端 code 换 open_id
        → open_id 映射内部成员 → 建立会话 → 进入系统
```

关键取舍：前端只负责跳转，`open_id → 成员` 的映射和会话签发都在服务端完成，前端拿不到也改不了身份。
