# 二、志愿时长网页应用

## 1. 页面构成

`VolunteerPanel.tsx` 从原来的"全功能本地测试页"改造成分 tab 的正式 H5 页面，共六个功能页：

| 页面 | 内容 |
|------|------|
| 活动列表与详情 | 可登记活动、时间、地点、说明；提供"去登记"跳转 |
| 志愿登记 | 选活动、填起止时间与备注、核对后提交；提交前二次确认 |
| 我的记录 | 本人登记记录、待审核／通过／驳回状态、审核意见 |
| 我的时长 | 本人已认定时长合计，支持按活动筛选 |
| 导出 | 下载本人有权限导出的 CSV |
| 管理 | 普通用户视图 / 管理员视图切换：活动创建、负责人补录、待审核列表、通过／驳回、汇总、全量导出 |

原型的"手填 member_id""手填审核人编号""手填负责人"输入框全部移除，身份统一从登录态自动获取。

## 2. 关键实现点

- **身份自动获取**：新增 `web/src/utils/feishuAuth.ts`，飞书内走 `h5sdk.requestAuthCode` → 后端换用户信息；本地 `127.0.0.1` 返回固定测试身份。应用 ID 在本仓库中已替换为占位符。
- **后端身份依赖桩**：`router.py` 新增 `get_current_member` / `get_current_reviewer` 依赖，本地返回固定测试用户，正式环境替换为 OAuth 实现即可，接口形状不变。
- **机器人入口**：`bot.py` 帮助卡片增加"打开网页版"按钮，地址读环境变量 `VOLUNTEER_WEB_URL`，未配置则不显示按钮，避免测试环境出现死链。
- **试运行提示**：页面顶部标注当前时长计算口径为试运行版本，业务规则待原负责人确认，符合"规则先保留待确认"的要求。
- **二次确认**：提交前弹确认框，取消则不发起请求，杜绝误提交。
- **管理后台**：负责人补录表单（来源标记 `admin`）、管理员全量记录 CSV 导出。

## 3. 边界拦截实测结果

以下均为本地启动后端 + 前端逐项点击/调接口验证，不是"接口存在"级别的推断：

| 场景 | 预期 | 实测结果 |
|------|------|----------|
| 同一成员同一时段重复登记 | 拒绝 | 返回 `overlapping_record` |
| 结束时间早于开始时间 | 参数校验拒绝 | 返回 `invalid_request` |
| 驳回时未填审核意见 | 拒绝 | 返回 `review_comment_required` |
| 已通过的记录再次审核 | 拒绝重复审核 | 状态判断生效，不产生二次有效审核 |
| 提交确认框点"取消" | 不写入 | 记录数不变，重新查询无新记录 |
| 时长计算 | 按 15 分钟取整、单次上限 120 分钟 | 实测出现 90 / 120 / 330 分钟等结果，1440 分钟被截断为 120 |
| 按活动筛选 | 只显示该活动的合计 | 该活动 3 条记录合计 330 分钟 |
| CSV 导出 | 触发文件下载 | 浏览器实际下载成功 |
| 后端停止后刷新页面 | 明确报错 | 前端显示网络错误，不伪装成"没有记录" |
