# 宣怀飞书项目实践档案

记录我在 `xuanhuaixclub/feishu-org-ai`（组织私有仓库）里承担的工作：**报销网页的飞书集成** 与 **志愿时长网页应用**。包含可复用的代码、我自己写的工程文档，以及可用 git 命令复核的贡献数据。

## 为什么这里不放完整源码

上游仓库是组织私有仓库，代码和提交记录不能直接搬到公开作品集；同时里面还有大量队友导入的既有代码。所以这个目录只放三类内容：

1. **我本人 100% 编写的源码文件**（已脱敏，去掉了应用 ID、密钥等）；
2. **我自己写的设计与部署文档**；
3. **git 统计出来的归属数据**（数字和命令，不含他人代码）。

这样既不泄露组织仓库内容，又能让任何人对"我做了什么"逐项核对。

## 更新方式

每完成一块新工作，做两件事：在 `CHANGELOG.md` 追加一条，然后重跑统计脚本刷新数据表。文档按模块分文件，新项目直接加一篇 `docs/0x-xxx.md`，不推翻既有结构。
