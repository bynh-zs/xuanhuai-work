# 宣怀项目作品集

收录我在宣怀社团（天津大学）参与的技术工作，作为个人作品集。**与协作仓库严格分离**：团队仓库的代码、队友的工作都不进这里，只放我本人可证明的产出与文档。

## 项目一览

| 目录 | 项目 | 我的职责 | 周期 |
|------|------|----------|------|
| `feishu-org-ai/` | 宣怀飞书智能服务台（机器人 + 报销网页 + 志愿时长网页） | 报销网页的飞书登录与主项目对接；志愿网页前端、机器人入口与身份框架 | 2026.10–2026.11 |

## 目录约定

- **一个项目一个目录**，项目内统一分三层：
  - `docs/`：设计、验收、踩坑记录
  - `code/`：仅本人 100% 编写且已脱敏的文件（不放混编文件）
  - `stats/`：git 统计出的贡献数据与可重跑的脚本
- 简历条目放各项目的 `resume/`
- 新增宣怀项目：同级新建目录，沿用同一结构，不改动已有项目

## 为什么不放完整源码

1. 协作仓库 `xuanhuaixclub/feishu-org-ai` 是组织私有仓库，代码不能公开；
2. 多数文件是多人混编（例如志愿页面 708 行中 429 行是本人所写），整文件复制等于把队友工作算成自己的；
3. 应用 ID、密钥等敏感值一律不入库。

代码归属的可信证据是提交作者、PR 记录和 `git blame`，不是复制出来的源码副本。

## 更新方式

每完成一块新工作：在对应项目 `CHANGELOG.md` 追加一条 → 重跑该项目 `scripts/collect-stats.ps1` 刷新数据 → 提交推送。
新项目直接加目录，首页表格同步加一行。
